# 积分商城

一个用 Python 标准库实现的积分商城 Web 应用，包含用户端与管理后台，界面适配手机与平板。

## 功能

- 注册 / 登录：邮箱 + 密码注册，登录支持「密码登录」与「邮箱验证码登录」
- 人机验证：点选顺序验证，拦截自动化发码
- 发码限频：同一邮箱 60 秒内仅可发送一次
- 三种货币：积分、钻石、绿宝石，可通过兑换码获得
- 兑换码：管理员可生成兑换码，发放货币或指定商品
- 签到、积分明细、商品兑换与兑换记录
- 管理员公告、优惠券（满减 / 折扣 / 立减 / 限定商品）、活动（浏览计时 / 答题 / 领奖）
- 瓜分红包与转账码：用户可把三种货币拆成红包或生成转账码
- 管理后台：商品上架 / 编辑 / 删除、卡密批量补货、用户管理、订单、兑换码、统计

## 本地运行

```bash
cp .env.example .env     # 按需填写配置
python3 server.py        # 默认 http://localhost:8000
```

仅使用 Python 标准库，无需安装第三方包。

> 未配置 `EMAIL_PASS` 时进入开发模式：验证码在接口中回显（`dev_code`），便于本地调试；配置后才会真正发送邮件。

## 配置

配置项通过环境变量或项目根目录的 `.env` 提供，`.env` 不会进入版本库。

| 变量 | 说明 |
| --- | --- |
| `SMTP_HOST` / `SMTP_PORT` | SMTP 服务地址（默认 `smtp.yeah.net:465`） |
| `EMAIL_USER` / `EMAIL_PASS` | 发件邮箱与授权码（不是邮箱登录密码） |
| `SMTP_FROM` | 发件人，默认同 `EMAIL_USER` |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | 管理员初始账号 |
| `DATA_KEY` | 运行数据快照的加密密钥 |

在 CI 环境中请把上述值配置为仓库 Secrets，不要写进代码或提交记录。

## 目录结构

```
server.py                      后端：接口、邮件、验证、业务逻辑
public/index.html              用户端与管理后台页面
docs/index.html                固定入口页
keepalive.sh                   进程守护与运行数据同步
report_url.sh                  访问地址播报
.github/workflows/tunnel.yml   自动化工作流
```

## 说明

- 运行数据只保存在服务端本地，不会以明文形式提交到版本库；自动化工作流使用加密快照做跨实例恢复，密钥由 `DATA_KEY` 提供。
- 访问地址会随运行环境变化，请通过 `docs/index.html` 提供的固定入口进入。
- 本项目为演示用途，请在正式使用前自行评估安全性与合规性。
